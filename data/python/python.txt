How Python Executes
A Python source file normally has a .py extension. The interpreter executes Python code. Python implementations can
compile source into bytecode before execution. For beginners, the important idea is that Python lets you write readable
source and execute it through the Python runtime.
Example
print("Source code runs through the Python runtime.")
Practice: Interview point: Python is commonly described as interpreted, although its implementation also uses compilation
to bytecode.

Binary search repeatedly halves a sorted search space. It runs in O(log n) time.

def binary_search(a, target):
lo, hi = 0, len(a)-1
while lo <= hi:
mid = (lo + hi) // 2
if a[mid] == target: return mid
if a[mid] < target: lo = mid + 1
else: hi = mid - 1
return -1

Binary Search
Binary search repeatedly halves a sorted search space. It runs in O(log n) time.

def binary_search(a, target):
lo, hi = 0, len(a)-1
while lo <= hi:
mid = (lo + hi) // 2
if a[mid] == target: return mid
if a[mid] < target: lo = mid + 1
else: hi = mid - 1
return -1

How Python Executes
A Python source file normally has a .py extension. The interpreter executes Python code. Python implementations can
compile source into bytecode before execution. For beginners, the important idea is that Python lets you write readable
source and execute it through the Python runtime.
Example
print("Source code runs through the Python runtime.")
Practice: Interview point: Python is commonly described as interpreted, although its implementation also uses compilation
to bytecode.
